# 评审量规

[English](review-rubric.md) | 中文

本仓库的评审对照本量规逐条给出结论与证据。自由式印象欢迎**补充**，但不能**替代**逐项判定。作者在开 PR 前自检；评审人只核对 diff 触及的条目，不必每次全查。

条目在这里，是因为它需要人的判断。当某条的承诺变得可机械检查，它就离开量规、变成带拒绝用例的门禁——每条的 `Gate candidate` 字段写明去向。`gov verify rubric` 检查本文件的结构；配对门禁检查双语对。

### R1 — 非平凡改动带诚实的笔记

- **查什么：** diff 改变了行为、架构、跨文件契约、流程或工具——且带新增或更新的 Agent Note，其 `## Alternatives considered` 列出真实的备选。
- **合格证据：** Problem 脱离解法独立成立；备选因明确理由落败，不是稻草人。
- **反模式：** 只记做了什么、不记打败了什么的笔记——存在但无诚实。
- **Gate candidate:** no —— 存在性已由 `gov note presence` 门禁把关；诚实是判断。

### R2 — 新增或修改的门禁证明自己能拒绝

- **查什么：** `gates.json` 里新增或修改的门禁、以及任何 `gov verify-*` 命令，在 `gov self-test` 里有拒绝用例。
- **合格证据：** 引入违规 → 断言变红 → 还原的用例。
- **反模式：** 只通过过的门禁——空转脚本（规则 6）。
- **Gate candidate:** no —— self-test 只跑已存在的用例；缺用例恰是评审要抓的。

### R3 — 大声失败，带肇事者名字

- **查什么：** 未知值、坏配置、缺失引用 abort 时点名肇事者；退出码 2=配置错，1=失败。
- **合格证据：** 错误文本包含坏值或 id 本身。
- **反模式：** 静默回退、默认吞掉错字、尽力而为地继续。
- **Gate candidate:** no —— 风格级判断；抽查触及路径。

### R4 — 安装面保持幂等且可精确反转

- **查什么：** 对 `gov init`/`uninstall` 的改动（创建的文件、接的钩子、manifest 条目）重复运行是 no-op、uninstall 能反转。
- **合格证据：** `tests/test_cli.py` 里覆盖新产物的往返测试，含冲突路径。
- **反模式：** 创建的文件不在 manifest 里；加装可能留下半初始化项目。
- **Gate candidate:** yes —— 由 init/uninstall 往返测试覆盖。

### R5 — 双语对整体合并

- **查什么：** 对外文档改动在同一 PR 里更新两种语言并重新确认配对。
- **合格证据：** PR 里 `gov verify pairing` 绿；两侧语义等价而非词面平行。
- **反模式：** 先落 `foo.md`、`foo.zh.md` "随后补"；机器味翻译。
- **Gate candidate:** yes —— 哈希已由 `gov verify pairing` 门禁把关；语义等价是判断。

### R6 — 检查集是选出来的，不是条件反射

- **查什么：** PR 写明跑了哪些门禁、为什么该集合对触及面充分。
- **合格证据：** `gov change-scope --base <ref>` 的输出（或其结论）加运行结果。
- **反模式：** "为保险全跑了"却无论证；静默跳过门禁。
- **Gate candidate:** no —— 充分性是判断；工具报告，选择者推理。

### R7 — 一个事实一个家

- **查什么：** 改动不复制在别处已有家的事实（见 [tiers.md](tiers.md)）；要么更新那个家，要么链接过去。
- **合格证据：** 每个被触及的文档都是它所说内容的权威之家。
- **反模式：** 同一事实的第二个落脚点——漂移那天就是错的。
- **Gate candidate:** no —— 漂移检测是判断。

### R8 — 活过这次 diff 的决策已被锁定

- **查什么：** 设计级选择（schema、契约、姿态）已记入 [decisions.md](decisions.md)，含选项与被否者。
- **合格证据：** 一条标 已决 的 D 号条目，或一条说明为何无需条目的笔记。
- **反模式：** 只活在 commit message 里的"已锁定"决策。
- **Gate candidate:** no —— 什么算设计级是判断。
