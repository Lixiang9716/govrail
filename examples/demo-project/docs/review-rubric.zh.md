# 评审量规

[English](review-rubric.md) | 中文

评审对照本量规逐条给出结论与证据。

### R1 — 非平凡改动带诚实的笔记

- **查什么：** 行为面 diff 带有真实备选的笔记。
- **合格证据：** 备选因明确理由落败。
- **反模式：** 只记做了什么、不记打败了什么。
- **Gate candidate:** no —— 存在性已由 `gov note presence` 把关。

### R2 — 新增或修改的门禁证明自己能拒绝

- **查什么：** 新门禁在 `gov self-test` 里有拒绝用例。
- **合格证据：** 引入违规 → 断言变红 → 还原的用例。
- **反模式：** 只通过过的门禁。
- **Gate candidate:** no —— 评审抓。
